# Ops 按需操作协议

沿用 Ops 主代理的目标、授权和安全边界。本技能不授权连接、初始化、系统变更或 Git 操作，不覆盖用户和项目规则。

仅读取本次触发的参考文件，文件路径相对本技能目录：

| 触发条件 | 参考文件 |
| --- | --- |
| Ops 任务开始读取记忆，或收尾评估、维护记忆 | [记忆协议](references/memory.md) |
| 规划初始化、持久化操作记录或 Git 提交 | [工作区与 Git](references/workspace-git.md) |
| 准备启动长任务、异步或临时托管任务 | [长任务](references/long-tasks.md) |

不把读取其他参考文件作为当前任务的前置。参考文件缺失时报告并停止依赖它的写入，不凭空补造协议；其余已授权的安全只读调查继续。
