# Ops 按需操作协议

沿用 [Ops 主代理](../../agents/ops.md) 的目标、授权和安全边界。本技能不授权连接、初始化、系统变更或 Git 操作，不覆盖用户和项目规则。

仅读取本次触发的参考文件，文件路径相对本技能目录：

| 触发条件 | 参考文件 |
| --- | --- |
| Ops 任务开始读取记忆，或收尾评估、维护记忆 | [记忆协议](references/memory.md) |
| 规划初始化、持久化操作记录或 Git 提交 | [工作区与 Git](references/workspace-git.md) |
| 准备启动长任务、异步或临时托管任务 | [长任务](references/long-tasks.md) |
| 开发或修改运维代码、脚本、配置及其测试 | [开发与验证](references/development-verification.md) |

不把其他参考文件作为当前任务前置。项目化使用时一并保留实际引用的文件，并将代理引用指向项目实际入口，不依赖全局安装目录。参考缺失时报告并停止依赖它的操作，不补造协议；其余安全只读调查继续。
