# Ops 客户端记忆协议

记忆只保留明确偏好、范围明确的选择和经验证的可复用经验，不是聊天记录、任务进度或授权来源。

## 位置与读取

- 根目录是运行 OpenCode 的客户端 `${XDG_STATE_HOME:-$HOME/.local/state}/opencode/memory`，解析为绝对路径。`user.md` 保存共享偏好，`ops.md` 保存 Ops 偏好，`projects/<项目标识>.md` 保存项目记忆；不加载 Coding 或其他项目记忆，除非任务确需。
- Git 项目标识为绝对真实路径 Git common directory 的 SHA-256；非 Git 项目用已明确客户端工作区根目录的绝对真实路径哈希。linked Worktree 共享记忆，不同克隆或移动目录不自动迁移；不使用 remote URL 或远端路径构造标识。
- 读取、写入或删除前检查根、父目录及目标真实路径，确认无符号链接指向仓库或其他位置，目标仍位于指定客户端目录。边界不明不读正文；缺失、不可用或失败时跳过并如实说明，不改存别处、不阻塞原任务。
- 新任务主动读取已有共享、Ops 和项目记忆；无法识别项目时只读前两者。大文件先读摘要，再取相关条目，不批量读历史。同任务不重复加载；任务或项目切换、压缩后缺失、已知内容变化时刷新，未成功读取不声称已加载。
- 当前指令、项目规则和实际状态优先，记忆只作背景。它不自动选择或连接主机，不决定 Low / High、不复用确认，也不替代 SSH 核验。

## 保存条件与授权

- 用户允许在上述客户端目录维护非敏感长期记忆，这是只读任务不持久化规则的有限例外，不授权项目、远端、配置、操作记录或 Git 写入。用户要求完全只读、不保存或不使用记忆时分别停止写入或读写。
- 任务完成、取消或明确暂停的收尾阶段评估，不在每次回复或工具调用后保存。只保存长期有用、可靠、范围明确、非敏感且尚未保存的信息；没有合格内容不写，不预建空模板。
- 明确长期偏好可以保存，一次性选择不升级为全局偏好，推测偏好不自动保存。每条含简短结论、范围、必要理由、来源与确认日期，经验注明适用条件和复核提示；失败任务不沉淀未经验证的成功结论。
- 不保存凭证、隐私、账号标识、内部地址、完整敏感输出、临时进度、易变状态或历史授权。主机特定经验不泛化，无法非敏感地区分目标时不保存。已有项目文档与操作记录不复制，仅保留必要导航。
- 记忆始终在客户端，不通过 SSH 创建或更新，不进入配置归档、项目或远程主机，不提交、推送或同步。`~/ai-ops` 和操作记录负责交接，不能用记忆替代或越权补写。

## 最小更新

- 只由主 agent 写入。更新前在根目录原子创建 `.write-lock`，记录会话与开始时间；锁占用时跳过并报告，不覆盖快照或自动删除疑似遗留锁。只释放本会话取得的锁。
- 持锁后重新读取相关条目，去重并修正过期结论；最新明确偏好取代同范围旧偏好，不同范围分别保留。冲突不明不覆盖；用户要求忘记时删除对应条目及摘要，不保留历史副本。
- 文件保持简短有效摘要和必要详情，不复制对话或日志。写后重新读取，核对范围与敏感信息；仅有实际变更时简要告知记住或忘记了什么。
