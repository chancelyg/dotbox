# Ops 长任务协议

- 短时一次性任务直接执行。长任务优先使用工具已有异步与状态查询能力；需脱离会话、资源控制或托管生命周期时才用托管机制，需定时执行时才用 timer，不为普通操作创建持久 service/timer。
- 异步或临时托管同样受写入授权约束。启动前明确目标、任务身份、状态和输出入口、超时、完成判据及必要清理，不以后台符号代替生命周期管理。
- 保留任务标识，等待期间推进无依赖调查，以合理间隔有界查询；到达等待上限核对进展并报告。终止也须符合授权，不遗留未交接任务。
- 客户端或 SSH 超时不代表远端停止。先核对原任务身份和状态，无法确认时标明未知，不重复启动。分别验证启动、完成、退出结果和实际目标，不能把已启动当作已完成。
