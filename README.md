# dotbox

dotbox 只维护客户端无关的 AI Agent Skills，不提供客户端配置或插件。

## 内容

| 路径 | 用途 |
| --- | --- |
| [`skills/`](skills/) | 共享工作方法与专项技能 |
| [`install.sh`](install.sh) | 交互式安装、升级 Skills |
| [`uninstall.sh`](uninstall.sh) | 交互式卸载 |
| [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)、[`LICENSES/`](LICENSES/) | 第三方来源与许可 |

## 安装与卸载

在本地克隆中运行（需要 Bash）：

```bash
./install.sh
# 1：安装；2：升级；0：退出

./uninstall.sh
# 1：卸载 Skills；2：全部卸载；0：退出
```

默认将包含 `SKILL.md` 的技能目录软链接到 `~/.agents/skills`，同名个人目录或其他链接会跳过，不会覆盖。可通过 `DOTBOX_SKILLS_DIR` 指定其他目录；安装、升级、卸载时需使用同一目录。

升级同步**当前本地仓库**，补充新技能并移除已删除技能的链接，不自动拉取远程代码。已有链接实时反映仓库内容；需要远程更新时先自行更新仓库，再选择升级。

卸载需确认，只删除指向当前仓库的技能链接，不删除源文件、目标目录或个人内容。目前只有 Skills，因此两个卸载入口行为相同。请勿在卸载前移动或删除本地仓库，否则需手动清理旧链接。

## 使用与维护

按所用客户端的原生机制发现或注册 Skills；客户端若不扫描默认目录，请指定合适的安装目录。更新后由客户端重新加载；文件可读不代表已加载或模型行为已经验证。

Skills 是按需加载的工作方法，不定义独立代理，也不改变工具权限。个人配置、凭证和机器状态不进入本仓库。
